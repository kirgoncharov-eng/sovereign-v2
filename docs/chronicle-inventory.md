# Опись стола для «Хроники срока»

Этап 1 задачи #302. Каждый элемент нынешнего `/game` партии 1978 года получает место в хронике.
Сверено с `main` на `68e6a92` (APP_VERSION 8.26). Это документ: код игры не меняется.

## Правило

Лента останавливается, только когда нужен ответ игрока, и тогда обязательно.
Вопрос для каждого элемента: **изменится ли игра, если промолчать?**

| Место | Значение |
| --- | --- |
| **Стоп** | Лента останавливается. Без ответа дальше не идёт; если есть «отложить», это видимый выбор с ценой |
| **Стоп при появлении** | Останавливает в квартал, когда пришло; отложенное ждёт в «Ждёт решения» и останавливает снова по сроку или порогу опоры |
| **Строка** | Датированная строка хроники: читается, ответа не требует |
| **Распорядиться** | Постоянная кнопка; ленту не держит, доступна на любой остановке и между ними |
| **Справка** | Открывается из шапки или строки; время на это не идёт |
| **Не переносим** | Роль выполняет сама лента или элемент противоречит хронике |

Предел остановок в квартал — дело плюс две (#302, гипотеза). При переполнении порядок такой:
истекает в этом квартале → опора у порога → давность. Не поместившееся переходит на следующий квартал;
то, что истекает сейчас, предел не откладывает.

## Что уже видно из кода

1. **В прототипе нет живого мира.** `web/lib/client/chronicle.ts` не вызывает `openDeskWhenDue`, поэтому `gs.world`
   не открывается: нет поручений по энергосети и больницам, секретаря, спонсора, мандата министра, правительства и писем.
   Пропустить в хронике нечего именно поэтому.
2. **В прототипе нет обещаний.** `/game` 1978 года передаёт `initPromises(offeredPromises(...).suggested)` при открытии,
   хроника — нет. Строк «обещание исполнено/нарушено» и их цены в хронике нет.
3. **В нынешней игре важное уже теряется.** Ответить на письмо человека (`replyToLetter`, `web/lib/game/stories.ts`)
   можно только пока открыта газета этого квартала: после «Следующего хода» `lastTurn` обнуляется и ответ недоступен.
   Предложения правительства помечены `needsReply: false` с текстом «не требуют обязательного обхода».
4. **Цена до подписи в прототипе неполная.** Показана подсказка варианта, но нет вероятности исполнения, расходов лагерей,
   строк обещаний, законов и договоров, которые `/game` показывает в `ChoicePreview`.

## Папка входящих: письма со сроком

Источник — `presidentialMessages` в `web/lib/client/presidential-inbox.ts`; `needsReply` и `deadline` уже посчитаны там.

| Элемент | Если промолчать | Хроника |
| --- | --- | --- |
| Проект без исполнителя (`unassigned`, `deadline`) | Работа не начнётся, срок не продлевается | **Стоп при появлении**; снова за квартал до срока |
| Больницы: ответ по графику врачей и продолжение (`healthNeedsAttention`, `aftermath`) | Срок ответа истекает | **Стоп** |
| Мандат министра (`minister-mandate.ts`, `phase: offered`, `due`) | Предложение истекает через 2 квартала | **Стоп при появлении**; снова в последний квартал |
| Спонсор: предложение, условие, давление (`sponsor-world.ts`) | Переход фазы, давление, отношения | **Стоп** на `offered`, `demanding`, `pressuring` |
| Просьба секретаря (`secretary.ts`, `answer === null`) | Ответ ждёт; влияет на доверие | **Стоп при появлении** |
| Финансовый след (`private-evidence.ts`) | `needsReply: false`; использование — действие | **Строка** по фазам; «использовать» — в **Распорядиться** |
| Письмо человека с ответом (`stories.ts`, `replyToLetter`) | Ответ пропадает со следующим ходом (п. 3) | **Стоп при появлении**; «не отвечать» — выбор |
| Письмо без ответа | — | **Строка** |

## Вопросы Кириллу

1. **Начало.** Сейчас в прототипе биография и взгляды выпадают по зерну, а в `/game` их выбирают.
   Предлагаю зерно по умолчанию и короткую строку «изменить» до первой подписи.
2. **Письма людей с ответом** сейчас теряются через квартал. Предлагаю сделать их стопом. Это меняет `/game`
   только в хронике; если хочешь, это можно исправить и на столе отдельной задачей.
3. **«Дело дня»** общее для всех и проверяется сервером. Предлагаю оставить его на `/game`,
   пока хроника не станет основной; иначе нужна отдельная серверная проверка.
4. **Предел остановок** «дело + 2» и порядок при переполнении — подтвердить или поменять до этапа 2.
