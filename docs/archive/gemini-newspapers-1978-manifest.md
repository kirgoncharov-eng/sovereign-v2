## 3. Правила подключения и спецификация вёрстки для GPT (интеграция, класс B)

### 3.1. Привязка шапок к изданиям 1978 года (`country === ALTERNATE_COUNTRY`)

1. В `web/lib/game/newspaper-editions.ts` функция `newspaperName(country, seed, turn)` для `"Беларусь · 1978"` уже возвращает одно из трёх названий из `NEWSPAPER_EDITIONS["Беларусь · 1978"]`:
   - `"Вестник республики"` → код `official` → `/art/newspapers-1978/masthead-official-{light|dark}.svg` (или `.webp`)
   - `"Минский лист"` → код `opposition` → `/art/newspapers-1978/masthead-opposition-{light|dark}.svg` (или `.webp`)
   - `"Рабочий полдень"` → код `regional` → `/art/newspapers-1978/masthead-regional-{light|dark}.svg` (или `.webp`)
2. Дополнительно при контекстном выборе газеты по характеру хода (если GPT подключает выбор голоса газеты по событию):
   - Утечки, «Протокол заседания в печати», расследование закрытых страниц договора 1956 года, отказы в проверке → `opposition` (**«Минский лист»**).
   - Дела районов, элеваторов, мостов, больниц, заводских магазинов и звонок редактора Веры Вербич (`journalistCall`) → `regional` (**«Рабочий полдень»**).
   - Государственные указы, бюджет, парламент, министерства и международные расчёты → `official` (**«Вестник республики»**).
3. **Архивные шесть стран (`LEGACY_COUNTRIES`) не затрагиваются:** они сохраняют прежний текстовый блок шапки.

### 3.2. Отличия макета первой полосы на экране `360 px` для трёх газет в `SovereignGame.jsx`

Чтобы на экране итога хода (`SovereignGame.jsx`, блок `lastTurn && counted`) три газеты различались не только картинкой шапки, но и вёрсткой первой полосы:

- **«Вестник республики» (`official`):**
  - Карточка: фон `#d9cfb2` (в `.sv-paper`) / `#24201c` (в `:root`), двойная казённая рамка.
  - Рубрика: плашка на всю ширину с верхней `2px` и нижней `1.5px` линейками (`ОФИЦИАЛЬНОЕ СООБЩЕНИЕ · <РУБРИКА>` слева, `ПОЛОСА 1` справа).
  - Заголовок решения (`#sv-turn-result`): `fontFamily: serif`, центровая выключка (`textAlign: "center"`), строгий прямой регистр.
  - Подпись к иллюстрации: `<caption/>. Фотохроника · Фото редакции`.
- **«Минский лист» (`opposition`):**
  - Карточка: чуть более холодный сероватый тон газетной бумаги II сорта (`#d2cbb6` в светлой теме / `#1e1c19` в тёмной).
  - Рубрика: инверсный красный штамп (`background: var(--red)`, `color: #f4eee1`, моноширинный шрифт `mono`) слева и пометка `БЕЗ КУПЮР` справа.
  - Заголовок решения (`#sv-turn-result`): узкий гротеск (`narrow`), левая выключка с вертикальной красной отбивкой `borderLeft: "4px solid var(--red)"`, `paddingLeft: 8`.
  - Иллюстрация: жёсткая сдвинутая тень `boxShadow: "3px 3px 0 var(--txt)"`, моноширинная подпись (`fontFamily: mono`, `Снимок ред.`).
  - Блок квартала / перехвата / стенограммы: пунктирная рамка `border: "1.5px dashed var(--txt)"` и машинописный шрифт `mono`.
- **«Рабочий полдень» (`regional`):**
  - Карточка: тёплая бумага `#dccfb0` (в светлой теме) / `#25211c` (в тёмной).
  - Рубрика: зелёный акцент `var(--grn)` слева и курсивная подпись `Принеманский край` (`fontFamily: serif, fontStyle: "italic"`) справа.
  - Заголовок решения (`#sv-turn-result`): `fontFamily: serif`, левая выключка (`textAlign: "left"`).
  - Подпись к иллюстрации: `<caption/>. Фото корр. «Рабочего полдня»`.
  - Блок реакции редакции/людей: обрамлённая колонка (`border: "1.5px solid var(--txt)"`, при участии Веры Вербич — плашка `Слово редактора · Вера Вербич`), нижний отделитель квартала — точечный пунктир `borderTop: "2px dotted var(--bdr2)"` с пометкой `ПО ОБЛАСТИ`.
