Проект для реализации по #223, часть #213. Кирилл утвердил общее направление 20 октября 2026.
[Согласованный план](https://github.com/kirgoncharov-eng/sovereign-v2/issues/213#issuecomment-6291014597).
Связанный эксперимент #66 — долгий план спасения; он не включён автоматически в этот пакет.

**Статус:** факты проверены по коду; меры и числа ниже — проект для проверки баланса, а не уже работающая игра.
Документ не подтверждает увлекательность и не разрешает релиз.
База: main `ff1825f4780785d81ac922cf7e7abdf75c79335c`, APP_VERSION 8.26.
Отдельная зависимость: #219/#221, head на момент проектирования
`bded5fd28eae3e97d3761557fe5deef966226116`; его изменённые реакции лагерей не считаются частью main.

## Задача игрока

«Ресурс падает. Я понимаю причину и могу предпринять осмысленное действие сейчас,
а не ждать подходящей следующей карточки».
Действие может пополнить запас, прекратить устранимые потери или обменять обязательство.
Оно не обязано спасать уже проигранное положение.

Политика должна открывать инструменты: аванс партнёра, поддержку группы, право потребовать исполнения.
Разнообразие конфликтов и ранней интриги остаётся отдельным обязательным направлением #214;
таблица ресурсов не заменяет эту работу.

## Матрица существующих ответов

Для всех шести опор также действуют эффекты текущего решения, отложенные последствия, законы,
кризисы, давление и пассивное восстановление. Карточка с подходящим эффектом не считается
управляемой инициативой: игрок не выбирает момент её появления.

| Опора | Характерные причины потерь | Что уже может помочь |
| --- | --- | --- |
| Влияние / politicalCapital | Переговоры, поручения, законы, потери от враждебных областей/правящих групп. | Успехи решений, пакты с областями/правящим лагерем, выборы и некоторые кадровые сцены. |
| Экономика / economy | Стоимость решений и программ, последствия договоров, больничное содержание, вредительство бизнеса и соседей. | Бюджетное распределение; результат экспортной программы +6 после исполнения; пакты с бизнесом/Россией; изменение существующих договорённостей. |
| Силовики / military | Давление, кризис силы, вредительство силового/национального лагерей и России. | Бюджет армии, соответствующие решения, пакты с силовым/национальным лагерем; улучшение отношений может убрать вредительство. |
| Репутация / externalReputation | Внешнеполитические уступки и нарушения, часть законов, вредительство Торгового союза. | Экспортная программа +3 после исполнения, пакт с Торговым союзом, дипломатические решения и законы. |
| Легитимность / internalLegitimacy | Репрессии, социальные провалы, обязательства и кризисы, вредительство нескольких внутренних групп. | Пресса, социальные решения, результат больниц/жилья/проверки закупок, пакты с гражданским/церковным лагерем. |
| Личный ресурс / personalResource | Личные поездки, проверки, переговоры, публичный приоритет (−1 за квартал), вредительство правящего лагеря. | Пассивное восстановление, эффекты отдельных решений; снятие личного приоритета прекращает его последующий расход. |

| Опора | Цена, срок и пробел управляемости |
| --- | --- |
| Влияние | Переговоры и проекты нередко сами расходуют влияние. Пакты и кадровые сцены требуют события; общего доступного запроса поддержки нет. |
| Экономика | Программы сначала стоят −3…−6 экономики и исполняются несколько кварталов; займ привязан к бюджету. Нет общего запроса краткой передышки. |
| Силовики | Бюджет привязан к календарю. Нет самостоятельного запроса снабжения; пополнение силы само по себе не устраняет риск переворота. |
| Репутация | Экспорт стоит −5 экономики и −2 влияния при запуске, затем требует исполнения. Нет общего способа самому начать урегулирование отношений. |
| Легитимность | Программы стоят денег/влияния и дают отложенный результат; пресса привязана к календарю. Нет общего адресного вмешательства до следующего дела. |
| Личный ресурс | Снять личный приоритет можно после открытия соответствующей программы: цена −2 влияния и −2 легитимности. Универсального делегирования для ранней партии нет. |

Дополнения к матрице:
- Отзыв закупочного мандата министра уже существует: −3 влияния, −1 личного ресурса;
  прекращает его специальную помощь и будущую связанную стоимость, не возвращает оплаченные заказы.
  Источник: `minister-mandate.ts: ministerActions, ministerDecision`.
- В больничном продолжении уже есть сокращение программы и другие ответы;
  это решения по конкретному подписанному обязательству с собственными сроками и последствиями.
  Источник: `health-aftermath.ts: aftermathActions/PLANS, stepHealthAftermath`.
- `government:release` не отменяет программу и не возвращает её бюджет.
  Источник: `government.ts: governmentActions, governmentDecision`.
- Поэтому нельзя писать «мер совсем нет». Нет раннего, системного и понятного доступа ко всем нужным ответам.

## Первый набор инициатив: кандидаты для замера

Числа — **стартовые гипотезы**, не утверждённый баланс.
Все значения — пункты шкал. Для каждого варианта показываются фактические изменения с учётом границ.
Положительный эффект не должен включать случайную проверку после подтверждения.
Более сложные проекты сохраняют собственную модель исполнения.

| Инициатива и смысл | Сейчас | Позже / ограничение |
| --- | --- | --- |
| Внутренний заём: получить передышку за счёт будущего бюджета. | Экономика +8, влияние −3, легитимность −2. | Через 3 квартала экономика −10. Один новый аванс за срок; общий лимит с внешними вариантами. |
| Запросить аванс внешнего партнёра под конкретную поставку. Альтернатива внутреннему займу. | Экономика +8, личный ресурс −2; цена уступки объявлена до подписи. | Через 3 квартала экономика −10. Плюс конкретное условие договора, выбранное из существующих тегов обязательств. |
| Согласовать повестку с внутренней группой: получить поддержку решений. | Влияние +6, экономика −3, личный ресурс −2. | Названный участник; одно такое соглашение за срок. Доступ зависит от отношений; не абстрактная поддержка любых элит. |
| Обеспечить снабжение гарнизонов. | Силовики +6, экономика −5, влияние −1. | Одна внеплановая поставка за срок. Это сила аппарата, а не автоматическое примирение с его руководством. |
| Урегулировать внешние претензии через конкретного партнёра. | Репутация +6, экономика −4, влияние −2. | Одно урегулирование за срок. Нельзя объявлять исполненным невыполненный договор или стирать будущий платёж. |
| Направить резерв на срочные выплаты людям. | Легитимность +6, экономика −5, влияние −1. | Один резерв выплат за срок. Не отменяет зарплаты/штаты и другие постоянные обязательства. |
| Передать текущие согласования заместителю. | Личный ресурс +7, влияние −4, экономика −1. | Одно делегирование за срок. При действующем личном приоритете сначала показан уже существующий способ снять его нагрузку. |

Это семь предложений, но шесть базовых ответов: внутренний и внешний авансы — альтернативы одного источника передышки.
Одноразовость — простой исходный ограничитель; увеличение резерва допускается только после замера,
а не сбрасыванием лимита при входе/выходе из красной зоны.

Для внешнего аванса предлагаются две разные политические цены:
- Российская делегация: приоритет её поставок; запрещено нарушать согласованное торговое условие.
- Торговый союз: открытая процедура по конкретному заказу; названное условие допуска и проверки.
Это проекты авторских условий, а не уже доступные кредиты.
Перед реализацией нужно сопоставить их с действующими тегами запретов/обещаний;
не изображать специфическое условие, если код отслеживает только общий тег.
Если общего тега недостаточно, точное обязательство требует отдельного типа данных и проверки.

При подписании внешнего договора запоминаются его участник, условие, срок, цена и последствия нарушения.
Предварительный кандидат допуска: отношение к группе ≥−20, к представителю ≥0;
точные границы проверяются на стилях. Запрет повторной выгоды относится к источнику аванса,
поэтому нельзя по очереди взять все три варианта или обновить лимит заменой представителя.

Согласование внутренней повестки предлагается у областей, палаты или правящей группы при их наличии.
Условие поддержки и реакция других заинтересованных групп должны быть авторскими:
задача #221 уже показывает, почему общий тег не заменяет смысл сделки.
Сами названия «открытость», «порядок», «договор» доступность не определяют.

## Сначала показать существующий выход

Если потери идут от личного приоритета, закупочного мандата или больничного обязательства,
первым предложением показывается соответствующее существующее действие с его настоящими последствиями.
Если оно недоступно, рядом объясняется причина.

Нельзя:
- вернуть бюджет программы, который уже израсходован;
- прекратить все будущие расходы одним общим переключателем;
- списать документально не установленный долг, объявив это взысканием;
- удалить кризис просто потому, что ресурс пополнился: у текущих кризисов отдельный жизненный цикл.

Взыскание подтверждённого долга остаётся условной инициативой следующего этапа:
нужны действительная запись долга и правило, исключающее второе взыскание.
Заморозка расходов тоже требует конкретного ещё не оплаченного платежа.
Ни один такой источник нельзя придумывать только ради спасения шкалы.

## Доступ и маршрут игрока

1. После первого принятого решения доступ к инициативам появляется в уже существующем окне ресурса.
   На первом деле новых блоков нет. Числа ≤22/≤10 усиливают предупреждение, но не являются
   условием рождения всех вариантов: игроку разрешено планировать заранее.
2. Строка «Можно предпринять» показывает подходящие ответы и причины блокировки.
   Для мер с отсрочкой ясно написано, когда они помогут. Полный кабинет не открывается автоматически.
3. Нажатие открывает одну короткую записку от подходящего исполнителя:
   задача, участник, эффект сейчас, обязательство и дата, остаток резерва.
4. Подтверждение использует личное вмешательство квартала и сохраняет результат.
   Сам календарь не продвигается; главное дело остаётся открытым и не заменяется другим.
5. Если уже использовано личное поручение, мера сообщает об общей квоте, а не даёт второе действие.
   При раннем доступе без world действует та же квота; открытие кабинета её не обнуляет.
6. Переход «ничего не предпринимать» всегда возможен без расходования квоты.

Для силы аппарата рядом показывается отдельная угроза от враждебных силовиков;
для легитимности — отдельно рейтинг. Не обещать, что пополнение одной шкалы исправит другую.

Если разумных мер не осталось, показать причины: резерв использован, нет партнёра,
другая опора не выдерживает цену или вмешательство квартала уже занято.
Не выдавать недоступную кнопку за возможность спасения и не обещать помощь любому состоянию.

## Правила исполнения и сохранений

Это требования к будущему A-изменению, а не описание реализованных полей.

- Модель инициатив — отдельный чистый модуль: список, проверка доступности, прогноз, подтверждение.
  Используются стабильные ID, полный номер хода и срока, версия схемы; названия реплик не служат ключами.
- Сохранение хранит потраченные источники, квартальную квоту, участника и подписанные обязательства.
  Новая необязательная секция отсутствует в старых сохранениях и безопасно инициализируется при загрузке.
- Резерв учитывается по сроку, а не по экрану, ресурсу или имени министра.
  Рефинансирование и повтор того же источника в первом пакете не разрешены.
- Личные поручения и инициативы проверяют общую квоту в обоих направлениях.
  Совместимость старого world.lastActionTurn обязательна; обход через ранний/полный кабинет тестируется.
- Подтверждение пересчитывает доступность по текущему состоянию.
  Отрицательная цена не может оставлять другой ресурс на 4 или ниже.
  При ограничении верхней границей показывается реальная, а не номинальная прибавка.
- Подписанная мера применяется ровно один раз. Перезагрузка, двойное нажатие, смена вкладки
  и пересоздание события не повторяют эффект и не обновляют резерв.
- Платежи используют единый механизм отложенных последствий с происхождением и устойчивым ID.
  Квартал выполнения определяется от момента подписи; он не сдвигается загрузкой.
  Совместимость с уже взятым бюджетным займом проверяется отдельно, не по свободному тексту.
- Будущие платежи сразу появляются в известных обязательствах. Нельзя потерять их на границе срока.
- Текущая открытая карточка сохраняется; её исход и цена прогнозируются заново по изменившимся ресурсам.
  Все источники инициативы попадают в отчёт, не подменяя источники предыдущего квартала.
- В архивных странах и «Деле дня» новая модель не активируется.
  Проверяются не только кнопки: сервис подтверждения тоже отказывает.
- Никаких вызовов моделей или внешних платных сервисов во время партии.

## Сценарии проверки реализации

| Сценарий | Проверяемое поведение |
| --- | --- |
| Каждая из шести опор на 21 и на 10 | Есть подходящий ответ либо точная причина недоступности; эффект/цена правдивы. |
| Запас ещё 35, но известен крупный платёж | Доступно планирование до красной зоны; известный платёж не скрыт. |
| Упадок до открытия топливного дела | Нужная записка доступна после первого решения без энергосети и полного кабинета. |

Баланс проверяется на одинаковых зёрнах и трёх сложностях с политическими и смешанными стратегиями,
включая игроков, которые применяют меру заранее, в последний момент и при каждой возможности.
Отдельно считаются ранние поражения, причины и решения до них.
100% выживания на конечной выборке не является доказательством ошибки;
сумма разных ресурсов не является универсальным критерием выгоды.

Две партии Кирилла проверяют то, чего не доказывает бот:
понятность помощи, ощущение собственного плана, разные политические возможности и желание играть дальше.
