# Суверен — политический триллер

Нарративная политическая игра на Next.js в духе Papers, Please. Игрок выбирает страну, сложность,
курс и биографию и правит, пока удерживает власть (срок — 20 ходов, сроков сколько удастся): ресурсы, фракции, люди с характером, союзы,
кризисы, выборы и сквозная интрига. Игра полностью офлайн: весь текст — авторская библиотека
сценариев, числа считает детерминированный движок. Ни модели, ни ключей, ни сети для партии не нужно.

На первом заходе «Начать игру» сразу открывает кабинет на мягкой сложности «Дебют».
После завершённой партии быстрый старт использует «Коалицию». Свой выбор страны, курса,
сложности и биографии доступен в раскрываемой анкете.

Таблица «Дела дня» принимает историю решений и воспроизводит партию на сервере: очки,
ходы и финальный титул не берутся из присланных клиентом чисел. Для динамических дел
запоминаются распределение бюджета, ответы прессе, подход в звонке и отмеченная строка доклада.
Старые сохранения можно доиграть, но без полной истории решений новый результат в таблицу не попадёт.
Проверка сохранений сохраняет отчёт хода, законы, обещания и последующие сроки без пересборки состояния.
Команда `/stop` отменяет и рассылку, и ожидающий вопрос об отзыве; старая подпись мини-приложения
не возвращает их до явной повторной подписки.

## Запуск

```bash
npm install
npm run dev                  # http://localhost:3000
npm run build:demo           # одностраничное демо → demo/dist/sovereign.html
```

Переменные окружения нужны только для таблицы «Дела дня» и Telegram-бота (см. `.env.example`).

Telegram Mini App и бот — пошагово:

1. В BotFather создайте бота (`/newbot`) и мини-приложение (`/newapp`) с адресом сайта.
   `NEXT_PUBLIC_SHARE_URL` — ссылка вида `https://t.me/<бот>/<приложение>`: по ней друзья
   попадают в таблицу друзей (параметр `startapp=ref_…`).
2. Заведите Redis (Upstash или Vercel KV) и пропишите переменные из `.env.example`.
3. Подключите вебхук и оформите профиль: откройте `$APP_URL/api/telegram/setup?key=$STATS_SECRET`.
   Вебхук ставится с тем же `TELEGRAM_WEBHOOK_SECRET`, что проверяет сервер; после смены секрета
   откройте ссылку ещё раз. Состояние вебхука видно на `$APP_URL/api/telegram`.
4. Утренняя рассылка «Дела дня» (`/api/cron/daily`) запускается Vercel Cron из `vercel.json`
   в 05:00 UTC (08:00 МСК); задайте `CRON_SECRET`.

Команды бота: `/start` — приветствие с обложкой, подписка и кнопки, `/daily` — дело дня, `/help` — правила,
`/stop` — отписка; на любой другой текст бот отвечает кнопкой игры. Профиль бота (вебхук, описание, команды,
кнопка «Играть») ставится одним запросом `/api/telegram/setup?key=<STATS_SECRET>`. Аватар и картинка
описания загружаются вручную в BotFather: `public/telegram-avatar.png`, `public/telegram-cover.png`.

Аналитика — свои анонимные счётчики в том же Redis, без сторонних сервисов: запуск, начало партии,
каждый ход, финал, «поделиться», «Дело дня» и возвращаемость по дню первого визита. Цифры —
на странице `/api/stats?key=<STATS_SECRET>` (`&days=30`, `&format=json`); там же — быстрая партия
или анкета и время до первого решения. Пять касаний по номеру версии на титульном экране помечают
устройство как тестовое: его действия в статистику не попадают (повторные пять касаний — снимают метку). Без Upstash счётчики
живут в памяти одного инстанса и теряются.

Отзывы: на экране итогов — оценка 1–5 и пара слов (`/api/feedback`), в боте — `/feedback`, три вопроса
подряд (ссылка `t.me/<бот>?start=feedback` открывает опрос сразу). Последние 500 отзывов — на странице
цифр. Автор подключает себе пересылку отзывов и утреннюю сводку командой `/admin <STATS_SECRET>`
в чате с ботом; сводка по запросу — `/stats`.

Поделиться итогом: на экране итогов — превью карточки и «Отправить другу». Ссылка ведёт на `/r?…`:
Telegram показывает её с картинкой (`/api/card?…`, рисуется на сервере через `next/og`, шрифты — `assets/fonts`),
а открывший ссылку видит итог друга и кнопку «Играть». В Telegram есть и «В историю» (`&f=story`, 1080×1920).
Имя бота в ссылках — `NEXT_PUBLIC_BOT_USERNAME` (по умолчанию `sovereign_game_bot`).

Возвращаемость: на экране итогов в Telegram — «Присылать по утрам». Игра просит разрешение писать
(`requestWriteAccess`), подпись `initData` проверяет `/api/subscribe`, игрок попадает в утреннюю рассылку.
Итог доигранной партии запоминается, и утренний крон (не раньше чем через 12 часов) один раз спрашивает
«Как вам игра?» — оценка кнопкой и два вопроса словами; ответы уходят в отзывы и автору.
Внутри Telegram игра разворачивается на весь экран, главное действие хода — на родной кнопке
Telegram, итогом можно поделиться через окно «Переслать», прогресс хранится в облаке Telegram.

## Архитектура

```
app/
  game/SovereignGame.jsx   UI: анкета, личное дело, ход, газета, финал
  api/daily|telegram|cron  таблица дела дня, бот, утренняя рассылка
lib/
  game/
    engine.ts              чистые функции: старт, план и итог хода, кризисы, выборы, концовки
    classic.ts             выбор дела и сборка текста хода из авторской библиотеки
    people.ts              характеры людей, «свой человек» и «червоточина», пакты
    data.ts                страны, фракции, действия, балансные лимиты, биографии
    sanitize.ts            проверка сохранённого состояния и авторских сценариев
  content/                 авторская библиотека: дела, сцены, провалы, интриги, доклады, вопросы прессы
  client/                  сохранение, пиксельная площадь и портреты, Telegram, звук
  server/                  KV, бот, лимит запросов
```

Как устроен ход:

1. `classic.ts` выбирает дело: эпизод интриги, проверка документа или пресс-конференция по графику,
   дело о людях и союзах, иначе — карточка из библиотеки по состоянию страны.
2. Каждый вариант помечен 1–2 тегами действий (`ACTIONS` в `data.ts`); `planTurn` детерминированно
   считает итог — ресурсы, фракции, людей, союзы, кризисы, выборы. Игрок видит цену варианта до выбора.
3. Текст хода — авторская сцена успеха или провала, эхо прошлых решений, реакции людей, газета.
4. `resolveTurn` применяет итог, партия сохраняется в localStorage.

## Дорожная карта

- [x] ИИ-режим удалён: игра только офлайн, авторская библиотека и детерминированный движок.

- [x] Этап 0 — стабилизация: закрытый эндпоинт, rate limit, валидация ответов, обработка ошибок,
      автосохранение, мобильная вёрстка, тесты движка.
- [x] Этап 1 — движок решает, модель рассказывает: варианты с тегами действий, числа
      из детерминированных правил, направление перемен видно до выбора, точную цену называет совет, симуляция баланса.
- [ ] Этап 1.5 — стриминг текста последствий, UI на TypeScript.
- [x] Этап 2а — внутренняя политика: опрос (партия лидера против трёх конкурентов),
      парламентские выборы на 10-м ходу и президентские на 20-м, импичмент, военный переворот,
      шесть концовок, текст последствий привязан к общей оценке хода.
- [x] Этап 2б — совет: четыре советника (политтехнолог, экономист, безопасность, дипломат)
      с качеством 1–3★ предлагают решения из своей области; сильный советник делает ход
      дешевле и выгоднее; число сборов за мандат ограничено сложностью.
- [x] Законы (`lib/content/laws.ts`): раз в несколько ходов парламент вносит законопроект — провести, отклонить
      или отправить на доработку. Принятый закон ложится в «Свод законов» и действует каждый ход: двигает опоры
      и отношение групп, приносит своё дело-последствие; озлобленные противники могут потребовать отмены.
      16 законов: от иноагентов и языка до обнуления сроков и люстрации; страновые — только своим странам.
- [x] Предвыборные обещания: перед первым ходом лидер берёт три из пяти (подсказаны три в духе курса);
      решения продвигают или нарушают их, в срок проверяются пороги; исполненное даёт доверие
      и благодарность тех, кому обещано, нарушенное — бьёт сильнее; влияют на вердикт и очки.
- [x] Этап 2в — отложенные последствия (эхо решений через 2–4 хода, видно заранее;
      слабый советник оставляет «недоработку»); враждебные фигуры сами становятся
      источником событий — интриги, ультиматумы, утечки.
- [x] Этап 3а — UX: закреплённый HUD с треком ходов и выборов, предпросмотр итога хода
      при наведении/фокусе, клавиши 1–9 и Enter, экран «Как править», живая загрузка,
      анимация итогов, контраст и размер шрифта, «Скопировать итог»; новые страны —
      Молдова, Армения, Казахстан.
- [x] Этап 4 — «бомба»: режим «Сценарии» без ИИ (мгновенные ходы, офлайн, ноль затрат),
      генератор библиотеки карточек, шанс успеха решений (провал исполнения), архив правителей,
      коллекция концовок, 10 достижений, открытие стран, быстрая партия.
- [x] Этап 4б — триллер: три сквозные интриги («Крот», «Заговор генералов», «Компромат»)
      по 4 авторских эпизода с ветвлением и шестью развязками; ИИ знает тайну и вплетает намёки,
      итог хода заканчивается клиффхэнгером; текст печатается как телеграмма; следующее
      событие предзагружается, пока игрок читает; «Триллер» (ИИ) снова режим по умолчанию.
- [x] Этап 4в — авторский триллер без ИИ: 129 сцен-последствий, нить интриги между эпизодами,
      «Триллер» (офлайн, бесплатно) — режим по умолчанию, «ИИ-режиссёр» — опция.
- [x] Этап 4г — ход как глава политического детектива: шапка (день, время, погода, место),
      развёрнутое событие со вторым абзацем, сцены-последствия по 5–7 предложений с диалогом,
      «тем временем» за кулисами, документ хода (утренние газеты / перехват спецслужб),
      крючок интриги; падежи столиц в авторском тексте.
- [x] Этап 4д — полировка к релизу: завязка интриги с первого хода, развязка и коллекция
      на финале, «Дело дня» (одна партия на всех, сравнение с друзьями), шеринг с вызовом,
      уникальные имена персонажей, склонения чисел, режим ИИ только при наличии ключа.
- [x] Этап 4е — визуальный язык «кабинет»: сукно и служебные бумаги, резолюции и штемпель,
      вечерняя газета, карандашные портреты персонажей (генерируются кодом по имени,
      `lib/client/portrait.ts`), значки опор власти в духе Reigns, звук печати и главы.
- [x] Этап 4ж — авторский совет: у каждого из 53 событий свои предложения советников
      (`lib/content/council-a.ts`, `council-b.ts`) со сценами успеха и провала.
- [ ] Этап 5 — каналы: Telegram Mini App, аналитика, вымышленные страны и английская версия.
- [ ] Этап 4 — метрики и экономика: стоимость партии, воронка по ходам, общий rate limit (Upstash/KV).
