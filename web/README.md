# Суверен — политическая симуляция

Нарративная политическая симуляция на Next.js. Игрок выбирает страну (Беларусь, Украина, Грузия),
сложность и идеологию и 20 ходов управляет государством: ресурсы, фракции, ключевые фигуры, кризисы.
Сюжет пишет языковая модель, а числа считает и ограничивает игровой движок.

## Запуск

```bash
cp .env.example .env.local   # вписать ключи
npm install
npm run dev                  # http://localhost:3000
```

Основной режим «Триллер» работает без ИИ, без ключей и без сети: события берутся из библиотеки
карточек (`lib/content/events.ts`), у каждого варианта — авторская сцена (`scenes.ts`), сквозные
интриги с эпизодами и строками-предвестиями — в `arcs.ts`. Ключи нужны только для необязательного
режима «ИИ-режиссёр».

Для разработки ИИ-режима без ключей: `AI_MOCK=1 npm run dev`.

Деплой (Vercel или любой хостинг Next.js): переменные окружения не обязательны. Без
`GOOGLE_AI_KEY` / `ANTHROPIC_API_KEY` сайт работает только в режиме «Триллер», а переключатель режимов скрыт
(`GET /api/ai` сообщает клиенту, доступен ли ИИ).

Telegram Mini App: укажите адрес сайта как Web App у бота в BotFather. Внутри Telegram игра
разворачивается на весь экран и делится итогом через родное окно «Переслать»; ссылку в тексте
задаёт `NEXT_PUBLIC_SHARE_URL`.

Пополнить библиотеку сценариев с помощью модели (офлайн, пакетно, с проверкой каждой карточки):

```bash
GOOGLE_AI_KEY=... npm run generate:content -- 10 12   # 10 партий по 12 карточек → lib/content/generated.ts
```

## Проверки

```bash
npm run check      # lint + typecheck + unit-тесты

```

## Архитектура

```
app/
  page.tsx                 страница игры
  game/SovereignGame.jsx   UI: экраны настройки, вступления, хода, финала
  api/ai/route.ts          единственный эндпоинт к модели
lib/
  game/
    types.ts               типы состояния
    data.ts                страны, фракции, фигуры, балансные лимиты
    engine.ts              чистые функции: старт партии, ход, кризисы, концовки
    sanitize.ts            проверка ответов модели и состояния от клиента
    prompts.ts             промпты (собираются только на сервере)
  server/
    llm.ts                 вызовы Gemini/Claude, fallback, повтор при негодном JSON
    rateLimit.ts           лимит запросов по IP
    mock.ts                заглушка модели (AI_MOCK=1)
  client/
    api.ts                 клиент к /api/ai
    save.ts                автосохранение в localStorage
```

Как устроен ход:

1. Клиент отправляет на `/api/ai` задачу (`setup` | `event` | `consequence` | `ending`) и состояние партии.
   Произвольный промпт отправить нельзя.
2. Сервер пересобирает состояние из справочников (`sanitizeState`), строит промпт и вызывает модель.
3. Ответ модели проверяется (`sanitize*`): неизвестные ключи отбрасываются, изменения ограничиваются
   лимитами из `data.ts` (`LIMITS`), при негодном ответе делается один повторный запрос.
4. Цену решения считает движок: модель помечает каждый вариант 1–2 тегами действий
   (`ACTIONS` в `data.ts`), а `planTurn` детерминированно считает итог хода — ресурсы, фракции,
   кризисы, давление сложности, вред от враждебных фракций. Игрок видит цену варианта до выбора,
   а модель пишет текст уже по посчитанному итогу.
5. Клиент применяет результат через движок (`resolveTurn`) и сохраняет партию.

Баланс проверяется симуляцией: `npm run balance`.

## Дорожная карта

- [x] Этап 0 — стабилизация: закрытый эндпоинт, rate limit, валидация ответов, обработка ошибок,
      автосохранение, мобильная вёрстка, тесты движка.
- [x] Этап 1 — движок решает, модель рассказывает: варианты с тегами действий, числа
      из детерминированных правил, цена решения видна до выбора, симуляция баланса.
- [ ] Этап 1.5 — стриминг текста последствий, UI на TypeScript.
- [x] Этап 2а — внутренняя политика: опрос (партия лидера против трёх конкурентов),
      парламентские выборы на 10-м ходу и президентские на 20-м, импичмент, военный переворот,
      шесть концовок, текст последствий привязан к общей оценке хода.
- [x] Этап 2б — совет: четыре советника (политтехнолог, экономист, безопасность, дипломат)
      с качеством 1–3★ предлагают решения из своей области; сильный советник делает ход
      дешевле и выгоднее; число сборов за мандат ограничено сложностью.
- [x] Этап 2в — отложенные последствия (эхо решений через 2–4 хода, видно заранее;
      слабый советник оставляет «недоработку»); враждебные фигуры сами становятся
      источником событий — интриги, ультиматумы, утечки.
- [x] Этап 3а — UX: закреплённый HUD с треком ходов и выборов, предпросмотр итога хода
      при наведении/фокусе, клавиши 1–9 и Enter, экран «Как править», живая загрузка,
      анимация итогов, контраст и размер шрифта, «Скопировать итог»; новые страны —
      Молдова, Армения, Казахстан.
- [x] Этап 4 — «бомба»: режим «Сценарии» без ИИ (мгновенные ходы, офлайн, ноль затрат),
      генератор библиотеки карточек, шанс успеха решений (провал исполнения), архив правителей,
      коллекция концовок, 10 достижений, открытие стран, быстрая партия.
- [x] Этап 4б — триллер: три сквозные интриги («Крот», «Заговор генералов», «Компромат»)
      по 4 авторских эпизода с ветвлением и шестью развязками; ИИ знает тайну и вплетает намёки,
      итог хода заканчивается клиффхэнгером; текст печатается как телеграмма; следующее
      событие предзагружается, пока игрок читает; «Триллер» (ИИ) снова режим по умолчанию.
- [x] Этап 4в — авторский триллер без ИИ: 129 сцен-последствий, нить интриги между эпизодами,
      «Триллер» (офлайн, бесплатно) — режим по умолчанию, «ИИ-режиссёр» — опция.
- [x] Этап 4г — ход как глава политического детектива: шапка (день, время, погода, место),
      развёрнутое событие со вторым абзацем, сцены-последствия по 5–7 предложений с диалогом,
      «тем временем» за кулисами, документ хода (утренние газеты / перехват спецслужб),
      крючок интриги; падежи столиц в авторском тексте.
- [x] Этап 4д — полировка к релизу: завязка интриги с первого хода, развязка и коллекция
      на финале, «Дело дня» (одна партия на всех, сравнение с друзьями), шеринг с вызовом,
      уникальные имена персонажей, склонения чисел, режим ИИ только при наличии ключа.
- [ ] Этап 5 — каналы: Telegram Mini App, аналитика, вымышленные страны и английская версия.
- [ ] Этап 4 — метрики и экономика: стоимость партии, воронка по ходам, общий rate limit (Upstash/KV).
