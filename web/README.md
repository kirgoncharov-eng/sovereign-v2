# Суверен — политический триллер

Нарративная политическая игра на Next.js в духе Papers, Please. Игрок выбирает страну, сложность,
курс и биографию и 20 ходов управляет государством: ресурсы, фракции, люди с характером, союзы,
кризисы, выборы и сквозная интрига. Игра полностью офлайн: весь текст — авторская библиотека
сценариев, числа считает детерминированный движок. Ни модели, ни ключей, ни сети для партии не нужно.

## Запуск

```bash
npm install
npm run dev                  # http://localhost:3000
npm run build:demo           # одностраничное демо → demo/dist/sovereign.html
```

Переменные окружения нужны только для таблицы «Дела дня» и Telegram-бота (см. `.env.example`).

Telegram Mini App и бот — пошагово:

1. В BotFather создайте бота (`/newbot`) и мини-приложение (`/newapp`) с адресом сайта.
   `NEXT_PUBLIC_SHARE_URL` — ссылка вида `https://t.me/<бот>/<приложение>`: по ней друзья
   попадают в таблицу друзей (параметр `startapp=ref_…`).
2. Заведите Redis (Upstash или Vercel KV) и пропишите переменные из `.env.example`.
3. Подключите вебхук:
   `curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook?url=$APP_URL/api/telegram&secret_token=$TELEGRAM_WEBHOOK_SECRET"`
4. Утренняя рассылка «Дела дня» (`/api/cron/daily`) запускается Vercel Cron из `vercel.json`
   в 05:00 UTC (08:00 МСК); задайте `CRON_SECRET`.

Команды бота: `/start` — приветствие с обложкой, подписка и кнопки, `/daily` — дело дня, `/help` — правила,
`/stop` — отписка; на любой другой текст бот отвечает кнопкой игры. Профиль бота (описание, команды,
кнопка «Играть») ставится одним запросом `/api/telegram/setup?key=<STATS_SECRET>`. Аватар и картинка
описания загружаются вручную в BotFather: `public/telegram-avatar.png`, `public/telegram-cover.png`.

Аналитика — свои анонимные счётчики в том же Redis, без сторонних сервисов: запуск, начало партии,
каждый ход, финал, «поделиться», «Дело дня» и возвращаемость по дню первого визита. Цифры —
на странице `/api/stats?key=<STATS_SECRET>` (`&days=30`, `&format=json`). Без Upstash счётчики
живут в памяти одного инстанса и теряются.
Внутри Telegram игра разворачивается на весь экран, главное действие хода — на родной кнопке
Telegram, итогом можно поделиться через окно «Переслать», прогресс хранится в облаке Telegram.

## Проверки

```bash
npm run check      # lint + typecheck + unit-тесты
npm test           # только тесты (node --test)
npm run balance    # симуляция баланса: 2000 партий на каждую сложность
npm run build
```

## Архитектура

```
app/
  game/SovereignGame.jsx   UI: анкета, личное дело, ход, газета, финал
  api/daily|telegram|cron  таблица дела дня, бот, утренняя рассылка
lib/
  game/
    engine.ts              чистые функции: старт, план и итог хода, кризисы, выборы, концовки
    classic.ts             выбор дела и сборка текста хода из авторской библиотеки
    people.ts              характеры людей, «свой человек» и «червоточина», пакты
    data.ts                страны, фракции, действия, балансные лимиты, биографии
    sanitize.ts            проверка сохранённого состояния и авторских сценариев
  content/                 авторская библиотека: дела, сцены, провалы, интриги, доклады, вопросы прессы
  client/                  сохранение, пиксельная площадь и портреты, Telegram, звук
  server/                  KV, бот, лимит запросов
```

Как устроен ход:

1. `classic.ts` выбирает дело: эпизод интриги, проверка документа или пресс-конференция по графику,
   дело о людях и союзах, иначе — карточка из библиотеки по состоянию страны.
2. Каждый вариант помечен 1–2 тегами действий (`ACTIONS` в `data.ts`); `planTurn` детерминированно
   считает итог — ресурсы, фракции, людей, союзы, кризисы, выборы. Игрок видит цену варианта до выбора.
3. Текст хода — авторская сцена успеха или провала, эхо прошлых решений, реакции людей, газета.
4. `resolveTurn` применяет итог, партия сохраняется в localStorage.

      автосохранение, мобильная вёрстка, тесты движка.
- [x] Этап 1 — движок решает, модель рассказывает: варианты с тегами действий, числа
      из детерминированных правил, цена решения видна до выбора, симуляция баланса.
- [ ] Этап 1.5 — стриминг текста последствий, UI на TypeScript.
- [x] Этап 2а — внутренняя политика: опрос (партия лидера против трёх конкурентов),
      парламентские выборы на 10-м ходу и президентские на 20-м, импичмент, военный переворот,
      шесть концовок, текст последствий привязан к общей оценке хода.
- [x] Этап 2б — совет: четыре советника (политтехнолог, экономист, безопасность, дипломат)
      с качеством 1–3★ предлагают решения из своей области; сильный советник делает ход
      дешевле и выгоднее; число сборов за мандат ограничено сложностью.

      слабый советник оставляет «недоработку»); враждебные фигуры сами становятся

      при наведении/фокусе, клавиши 1–9 и Enter, экран «Как править», живая загрузка,
