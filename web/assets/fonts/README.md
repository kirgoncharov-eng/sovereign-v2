Шрифты для серверной карточки итога (`app/api/card`): Satori читает только ttf/otf/woff.

- `handjet-*.ttf` — Handjet (SIL Open Font License 1.1): латиница и кириллица из `public/fonts/*.woff2`, склеены в один файл.
- `LiberationSerif-*.ttf` — Liberation Serif (SIL Open Font License 1.1), урезаны до латиницы, кириллицы и знаков.
