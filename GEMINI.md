При лимите отметить блокировку; назначение само по себе не подтверждает начало работы.

Перед правками — [studio:claim] с подписью Gemini, моделью, веткой и файлами. При лимите —
[studio:handoff] с SHA, готовым, проверками, незакоммиченным и следующим шагом; принимая
работу — [studio:takeover]. Не правь файлы работающего автора одновременно. Не включай
чужие незакоммиченные изменения в свой PR. Соавтор кода не одобряет свой итоговый PR.

Ответы и независимое ревью — в обсуждении конкретной задачи/PR, с подписью Gemini и полным SHA.
Наличие уведомления не означает, что агент уже начал работу; ответом явно подтвердить получение.

## Эффективное использование моделей и лимитов

Базовый режим по решению Кирилла 20 октября 2026 — **Gemini 3.8 Flash / Medium**.
Перед каждым запросом применяй раздел «Выбор модели и сохранение контекста» в AGENTS.md.
Он определяет рекомендацию переключения, возврат после сложного этапа и восстановление контекста.
Если Medium недоступен в приложении, сообщи доступные режимы, не называй High средним.
Ниже — практические правила подготовки ассетов; общий выбор моделей определяется AGENTS.md.

1. **Каскад моделей (Flash для процесса, Gemini 4 для ключевых решений):**
   - **Gemini 3.8 Flash / Medium:** рутинные операции, чтение диффов и логов, манифесты, поиск по коду.
   - **Gemini 4 Argon / Medium:** рекомендация для глубокой визуальной приёмки и режиссуры стиля;
     High — при конкретной сложности. Не утверждать, что переключение выполнено, без подтверждения интерфейса.
2. **Пакетная работа над визуалом (Batching):**
   - Не генерировать по одной иллюстрации с пошаговым обсуждением. Собирать требования в **связанные пакеты по 3–5 сцен** (как в `alt_wages`: завязка + 3 исхода) и запускать сабагента одним полным ТЗ.
3. **Контроль длины контекста (`/compact`):**
   - Так как долговременная память проекта сохраняется в файлах (`STATUS.md`, `docs/`, `art-source/`), после завершения и сдачи крупного блока использовать `/compact` или начинать новый тред, чтобы длинная история со скриншотами не сжигала квоту токенов на простых действиях.
4. **Инженерная обработка — локальным скриптам и GPT:**
   - Масштабирование, конвертация в WebP (`sips` + `libvips`, `Q=84`), подсчёт SHA-256 и сборка контактных листов выполняются одним локальным скриптом на Mac за 2 секунды (0 токенов рассуждения).
   - Интеграция в игровой код (`TS`/`JSX`), запуск тестов (`npm run check && npm run build`) и оформление PR на GitHub передаются `GPT/Codex`.
5. **Автономные задачи «под ключ»:**
   - Формулировать задачу комплексным циклом (генерация → конвертация в WebP → контактный лист → манифест → передача в задаче/PR).
     STATUS.md меняется только отдельным статус-PR; рабочий пакет его не трогает.
