# Вычитка текста

Текст — ядро игры. Тесты ловят пустые слоты и ошибки рода, но не ловят бессмыслицу. Её находит только чтение.

## Шаги

1. Сгенерировать 2–3 партии разных стран и сложностей:
   ```
   cd web && node scripts/read-run.ts Казахстан 21 coalition > <scratchpad>/run-kz.txt
   node scripts/read-run.ts Грузия 7 debut > <scratchpad>/run-ge.txt
   ```
2. Прочитать целиком, как игрок. Отмечать:
   - **кто говорит** — реакция от того, кого решение касается, и с его интересом (силовики не радуются амнистии);
   - **место и время** — шапка дела совпадает с родом дела, сезон с погодой;
   - **связность** — следующий эпизод интриги помнит предыдущий, газета пишет о том, что вы решили;
   - **цена** — объяснение, почему решение стоит казны или доверия, звучит правдоподобно;
   - **повторы** — одна фраза дважды за партию (сводка повторов есть в `node scripts/stress.ts`);
   - **род и число** — «Кремль передаёт», «Западные партнёры ставят»;
   - **реальные люди и партии** — их быть не должно;
   - **канцелярит** — «осуществить мероприятия», «в рамках».
3. Каждую находку — цитатой и файлом источника (`grep -rn "<кусок фразы>" web/lib`).
4. Исправлять в контенте, не в движке, если ошибка в тексте. После правки — `npm run check` и повторная партия той же страны и зерна.
5. Новые правила, найденные при вычитке, — тестом в `lib/game/text.test.ts`, чтобы ошибка не вернулась.
